# Symfony security (stack domains)

Orchestrator for **Symfony** (PHP). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-symfony-backend-server/` | Backend and server-side security |
| `stack-symfony-api-integration/` | API and integration security |
| `stack-symfony-identity-access/` | Identity, authentication, and access control |
| `stack-symfony-cryptography/` | Cryptography and key management |
| `stack-symfony-secrets-config/` | Secrets and configuration |
| `stack-symfony-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-symfony-ai-ml-security/` | AI and ML system security |
| `stack-symfony-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-symfony-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-symfony-payments-fintech/` | Payments and financial flows |
| `stack-symfony-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-symfony-server-framework-security/` | Server framework and runtime security |
| `stack-symfony-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-symfony-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-symfony-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

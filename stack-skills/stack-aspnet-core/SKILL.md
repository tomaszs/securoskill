# ASP.NET Core security (stack domains)

Orchestrator for **ASP.NET Core** (.NET). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-aspnet-core-backend-server/` | Backend and server-side security |
| `stack-aspnet-core-api-integration/` | API and integration security |
| `stack-aspnet-core-identity-access/` | Identity, authentication, and access control |
| `stack-aspnet-core-cryptography/` | Cryptography and key management |
| `stack-aspnet-core-network-transport/` | Network and transport security |
| `stack-aspnet-core-secrets-config/` | Secrets and configuration |
| `stack-aspnet-core-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-aspnet-core-ai-ml-security/` | AI and ML system security |
| `stack-aspnet-core-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-aspnet-core-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-aspnet-core-payments-fintech/` | Payments and financial flows |
| `stack-aspnet-core-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-aspnet-core-server-framework-security/` | Server framework and runtime security |
| `stack-aspnet-core-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-aspnet-core-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-aspnet-core-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

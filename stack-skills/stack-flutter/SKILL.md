# Flutter security (stack domains)

Orchestrator for **Flutter** (Mobile). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-flutter-frontend-client/` | Frontend and client-side security |
| `stack-flutter-backend-server/` | Backend and server-side security |
| `stack-flutter-api-integration/` | API and integration security |
| `stack-flutter-identity-access/` | Identity, authentication, and access control |
| `stack-flutter-cryptography/` | Cryptography and key management |
| `stack-flutter-mobile-security/` | Mobile application security |
| `stack-flutter-ai-ml-security/` | AI and ML system security |
| `stack-flutter-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-flutter-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-flutter-payments-fintech/` | Payments and financial flows |
| `stack-flutter-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-flutter-server-framework-security/` | Server framework and runtime security |
| `stack-flutter-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-flutter-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-flutter-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

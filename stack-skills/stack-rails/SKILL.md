# Ruby on Rails security (stack domains)

Orchestrator for **Ruby on Rails** (Ruby). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-rails-backend-server/` | Backend and server-side security |
| `stack-rails-api-integration/` | API and integration security |
| `stack-rails-identity-access/` | Identity, authentication, and access control |
| `stack-rails-cryptography/` | Cryptography and key management |
| `stack-rails-secrets-config/` | Secrets and configuration |
| `stack-rails-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-rails-ai-ml-security/` | AI and ML system security |
| `stack-rails-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-rails-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-rails-payments-fintech/` | Payments and financial flows |
| `stack-rails-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-rails-server-framework-security/` | Server framework and runtime security |
| `stack-rails-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-rails-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-rails-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

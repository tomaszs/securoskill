# Prisma security (stack domains)

Orchestrator for **Prisma** (ORM / data access). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-prisma-backend-server/` | Backend and server-side security |
| `stack-prisma-api-integration/` | API and integration security |
| `stack-prisma-identity-access/` | Identity, authentication, and access control |
| `stack-prisma-data-databases/` | Data protection and databases |
| `stack-prisma-cryptography/` | Cryptography and key management |
| `stack-prisma-ai-ml-security/` | AI and ML system security |
| `stack-prisma-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-prisma-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-prisma-payments-fintech/` | Payments and financial flows |
| `stack-prisma-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-prisma-server-framework-security/` | Server framework and runtime security |
| `stack-prisma-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-prisma-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-prisma-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

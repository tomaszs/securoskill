# Angular security (stack domains)

Orchestrator for **Angular** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-angular-frontend-client/` | Frontend and client-side security |
| `stack-angular-backend-server/` | Backend and server-side security |
| `stack-angular-api-integration/` | API and integration security |
| `stack-angular-identity-access/` | Identity, authentication, and access control |
| `stack-angular-cryptography/` | Cryptography and key management |
| `stack-angular-ai-ml-security/` | AI and ML system security |
| `stack-angular-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-angular-email-notifications/` | Email and notifications security |
| `stack-angular-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-angular-payments-fintech/` | Payments and financial flows |
| `stack-angular-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-angular-web-framework-security/` | Web UI framework security |
| `stack-angular-server-framework-security/` | Server framework and runtime security |
| `stack-angular-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-angular-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-angular-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# Vercel security (stack domains)

Orchestrator for **Vercel** (Platform). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-vercel-backend-server/` | Backend and server-side security |
| `stack-vercel-api-integration/` | API and integration security |
| `stack-vercel-identity-access/` | Identity, authentication, and access control |
| `stack-vercel-cryptography/` | Cryptography and key management |
| `stack-vercel-cloud-infrastructure/` | Cloud and infrastructure security |
| `stack-vercel-secrets-config/` | Secrets and configuration |
| `stack-vercel-ai-ml-security/` | AI and ML system security |
| `stack-vercel-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-vercel-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-vercel-payments-fintech/` | Payments and financial flows |
| `stack-vercel-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-vercel-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-vercel-server-framework-security/` | Server framework and runtime security |
| `stack-vercel-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-vercel-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-vercel-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# SvelteKit security (stack domains)

Orchestrator for **SvelteKit** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-sveltekit-frontend-client/` | Frontend and client-side security |
| `stack-sveltekit-backend-server/` | Backend and server-side security |
| `stack-sveltekit-api-integration/` | API and integration security |
| `stack-sveltekit-identity-access/` | Identity, authentication, and access control |
| `stack-sveltekit-cryptography/` | Cryptography and key management |
| `stack-sveltekit-secrets-config/` | Secrets and configuration |
| `stack-sveltekit-ai-ml-security/` | AI and ML system security |
| `stack-sveltekit-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-sveltekit-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-sveltekit-payments-fintech/` | Payments and financial flows |
| `stack-sveltekit-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-sveltekit-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-sveltekit-web-framework-security/` | Web UI framework security |
| `stack-sveltekit-server-framework-security/` | Server framework and runtime security |
| `stack-sveltekit-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-sveltekit-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-sveltekit-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# Fastify security (stack domains)

Orchestrator for **Fastify** (Node.js server). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-fastify-backend-server/` | Backend and server-side security |
| `stack-fastify-api-integration/` | API and integration security |
| `stack-fastify-identity-access/` | Identity, authentication, and access control |
| `stack-fastify-cryptography/` | Cryptography and key management |
| `stack-fastify-network-transport/` | Network and transport security |
| `stack-fastify-secrets-config/` | Secrets and configuration |
| `stack-fastify-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-fastify-ai-ml-security/` | AI and ML system security |
| `stack-fastify-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-fastify-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-fastify-payments-fintech/` | Payments and financial flows |
| `stack-fastify-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-fastify-server-framework-security/` | Server framework and runtime security |
| `stack-fastify-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-fastify-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-fastify-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

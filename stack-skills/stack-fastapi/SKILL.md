# FastAPI security (stack domains)

Orchestrator for **FastAPI** (Python). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-fastapi-backend-server/` | Backend and server-side security |
| `stack-fastapi-api-integration/` | API and integration security |
| `stack-fastapi-identity-access/` | Identity, authentication, and access control |
| `stack-fastapi-cryptography/` | Cryptography and key management |
| `stack-fastapi-network-transport/` | Network and transport security |
| `stack-fastapi-secrets-config/` | Secrets and configuration |
| `stack-fastapi-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-fastapi-ai-ml-security/` | AI and ML system security |
| `stack-fastapi-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-fastapi-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-fastapi-payments-fintech/` | Payments and financial flows |
| `stack-fastapi-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-fastapi-server-framework-security/` | Server framework and runtime security |
| `stack-fastapi-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-fastapi-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-fastapi-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

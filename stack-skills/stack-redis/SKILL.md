# Redis security (stack domains)

Orchestrator for **Redis** (Database). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-redis-backend-server/` | Backend and server-side security |
| `stack-redis-api-integration/` | API and integration security |
| `stack-redis-identity-access/` | Identity, authentication, and access control |
| `stack-redis-data-databases/` | Data protection and databases |
| `stack-redis-cryptography/` | Cryptography and key management |
| `stack-redis-ai-ml-security/` | AI and ML system security |
| `stack-redis-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-redis-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-redis-payments-fintech/` | Payments and financial flows |
| `stack-redis-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-redis-server-framework-security/` | Server framework and runtime security |
| `stack-redis-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-redis-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-redis-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

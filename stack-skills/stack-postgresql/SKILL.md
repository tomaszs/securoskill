# PostgreSQL security (stack domains)

Orchestrator for **PostgreSQL** (Database). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-postgresql-backend-server/` | Backend and server-side security |
| `stack-postgresql-api-integration/` | API and integration security |
| `stack-postgresql-identity-access/` | Identity, authentication, and access control |
| `stack-postgresql-data-databases/` | Data protection and databases |
| `stack-postgresql-cryptography/` | Cryptography and key management |
| `stack-postgresql-ai-ml-security/` | AI and ML system security |
| `stack-postgresql-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-postgresql-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-postgresql-payments-fintech/` | Payments and financial flows |
| `stack-postgresql-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-postgresql-server-framework-security/` | Server framework and runtime security |
| `stack-postgresql-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-postgresql-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-postgresql-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

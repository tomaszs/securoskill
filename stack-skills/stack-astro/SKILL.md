# Astro security (stack domains)

Orchestrator for **Astro** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-astro-frontend-client/` | Frontend and client-side security |
| `stack-astro-backend-server/` | Backend and server-side security |
| `stack-astro-api-integration/` | API and integration security |
| `stack-astro-identity-access/` | Identity, authentication, and access control |
| `stack-astro-cryptography/` | Cryptography and key management |
| `stack-astro-secrets-config/` | Secrets and configuration |
| `stack-astro-ai-ml-security/` | AI and ML system security |
| `stack-astro-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-astro-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-astro-payments-fintech/` | Payments and financial flows |
| `stack-astro-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-astro-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-astro-web-framework-security/` | Web UI framework security |
| `stack-astro-server-framework-security/` | Server framework and runtime security |
| `stack-astro-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-astro-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-astro-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

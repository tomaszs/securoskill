# Remix security (stack domains)

Orchestrator for **Remix** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-remix-frontend-client/` | Frontend and client-side security |
| `stack-remix-backend-server/` | Backend and server-side security |
| `stack-remix-api-integration/` | API and integration security |
| `stack-remix-identity-access/` | Identity, authentication, and access control |
| `stack-remix-cryptography/` | Cryptography and key management |
| `stack-remix-secrets-config/` | Secrets and configuration |
| `stack-remix-ai-ml-security/` | AI and ML system security |
| `stack-remix-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-remix-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-remix-payments-fintech/` | Payments and financial flows |
| `stack-remix-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-remix-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-remix-web-framework-security/` | Web UI framework security |
| `stack-remix-server-framework-security/` | Server framework and runtime security |
| `stack-remix-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-remix-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-remix-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

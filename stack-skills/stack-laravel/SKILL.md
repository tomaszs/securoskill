# Laravel security (stack domains)

Orchestrator for **Laravel** (PHP). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-laravel-backend-server/` | Backend and server-side security |
| `stack-laravel-api-integration/` | API and integration security |
| `stack-laravel-identity-access/` | Identity, authentication, and access control |
| `stack-laravel-cryptography/` | Cryptography and key management |
| `stack-laravel-secrets-config/` | Secrets and configuration |
| `stack-laravel-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-laravel-ai-ml-security/` | AI and ML system security |
| `stack-laravel-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-laravel-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-laravel-payments-fintech/` | Payments and financial flows |
| `stack-laravel-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-laravel-server-framework-security/` | Server framework and runtime security |
| `stack-laravel-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-laravel-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-laravel-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# TypeORM security (stack domains)

Orchestrator for **TypeORM** (ORM / data access). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-typeorm-backend-server/` | Backend and server-side security |
| `stack-typeorm-api-integration/` | API and integration security |
| `stack-typeorm-identity-access/` | Identity, authentication, and access control |
| `stack-typeorm-data-databases/` | Data protection and databases |
| `stack-typeorm-cryptography/` | Cryptography and key management |
| `stack-typeorm-ai-ml-security/` | AI and ML system security |
| `stack-typeorm-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-typeorm-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-typeorm-payments-fintech/` | Payments and financial flows |
| `stack-typeorm-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-typeorm-server-framework-security/` | Server framework and runtime security |
| `stack-typeorm-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-typeorm-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-typeorm-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# Flask security (stack domains)

Orchestrator for **Flask** (Python). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-flask-backend-server/` | Backend and server-side security |
| `stack-flask-api-integration/` | API and integration security |
| `stack-flask-identity-access/` | Identity, authentication, and access control |
| `stack-flask-cryptography/` | Cryptography and key management |
| `stack-flask-network-transport/` | Network and transport security |
| `stack-flask-secrets-config/` | Secrets and configuration |
| `stack-flask-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-flask-ai-ml-security/` | AI and ML system security |
| `stack-flask-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-flask-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-flask-payments-fintech/` | Payments and financial flows |
| `stack-flask-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-flask-server-framework-security/` | Server framework and runtime security |
| `stack-flask-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-flask-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-flask-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

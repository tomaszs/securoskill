# Kubernetes security (stack domains)

Orchestrator for **Kubernetes** (Infrastructure). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-kubernetes-backend-server/` | Backend and server-side security |
| `stack-kubernetes-api-integration/` | API and integration security |
| `stack-kubernetes-identity-access/` | Identity, authentication, and access control |
| `stack-kubernetes-cryptography/` | Cryptography and key management |
| `stack-kubernetes-cloud-infrastructure/` | Cloud and infrastructure security |
| `stack-kubernetes-containers-k8s/` | Containers and Kubernetes |
| `stack-kubernetes-devsecops-cicd/` | DevSecOps and CI/CD |
| `stack-kubernetes-ai-ml-security/` | AI and ML system security |
| `stack-kubernetes-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-kubernetes-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-kubernetes-payments-fintech/` | Payments and financial flows |
| `stack-kubernetes-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-kubernetes-server-framework-security/` | Server framework and runtime security |
| `stack-kubernetes-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-kubernetes-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-kubernetes-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# Svelte security (stack domains)

Orchestrator for **Svelte** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-svelte-frontend-client/` | Frontend and client-side security |
| `stack-svelte-backend-server/` | Backend and server-side security |
| `stack-svelte-api-integration/` | API and integration security |
| `stack-svelte-identity-access/` | Identity, authentication, and access control |
| `stack-svelte-cryptography/` | Cryptography and key management |
| `stack-svelte-ai-ml-security/` | AI and ML system security |
| `stack-svelte-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-svelte-email-notifications/` | Email and notifications security |
| `stack-svelte-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-svelte-payments-fintech/` | Payments and financial flows |
| `stack-svelte-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-svelte-web-framework-security/` | Web UI framework security |
| `stack-svelte-server-framework-security/` | Server framework and runtime security |
| `stack-svelte-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-svelte-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-svelte-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

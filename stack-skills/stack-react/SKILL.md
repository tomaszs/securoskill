# React security (stack domains)

Orchestrator for **React** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-react-frontend-client/` | Frontend and client-side security |
| `stack-react-backend-server/` | Backend and server-side security |
| `stack-react-api-integration/` | API and integration security |
| `stack-react-identity-access/` | Identity, authentication, and access control |
| `stack-react-cryptography/` | Cryptography and key management |
| `stack-react-ai-ml-security/` | AI and ML system security |
| `stack-react-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-react-email-notifications/` | Email and notifications security |
| `stack-react-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-react-payments-fintech/` | Payments and financial flows |
| `stack-react-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-react-web-framework-security/` | Web UI framework security |
| `stack-react-server-framework-security/` | Server framework and runtime security |
| `stack-react-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-react-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-react-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

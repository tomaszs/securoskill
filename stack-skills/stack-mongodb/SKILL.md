# MongoDB security (stack domains)

Orchestrator for **MongoDB** (Database). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-mongodb-backend-server/` | Backend and server-side security |
| `stack-mongodb-api-integration/` | API and integration security |
| `stack-mongodb-identity-access/` | Identity, authentication, and access control |
| `stack-mongodb-data-databases/` | Data protection and databases |
| `stack-mongodb-cryptography/` | Cryptography and key management |
| `stack-mongodb-ai-ml-security/` | AI and ML system security |
| `stack-mongodb-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-mongodb-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-mongodb-payments-fintech/` | Payments and financial flows |
| `stack-mongodb-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-mongodb-server-framework-security/` | Server framework and runtime security |
| `stack-mongodb-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-mongodb-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-mongodb-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

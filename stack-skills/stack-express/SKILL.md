# Express.js security (stack domains)

Orchestrator for **Express.js** (Node.js server). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-express-backend-server/` | Backend and server-side security |
| `stack-express-api-integration/` | API and integration security |
| `stack-express-identity-access/` | Identity, authentication, and access control |
| `stack-express-cryptography/` | Cryptography and key management |
| `stack-express-network-transport/` | Network and transport security |
| `stack-express-secrets-config/` | Secrets and configuration |
| `stack-express-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-express-ai-ml-security/` | AI and ML system security |
| `stack-express-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-express-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-express-payments-fintech/` | Payments and financial flows |
| `stack-express-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-express-server-framework-security/` | Server framework and runtime security |
| `stack-express-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-express-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-express-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

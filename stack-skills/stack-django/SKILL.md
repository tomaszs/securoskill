# Django security (stack domains)

Orchestrator for **Django** (Python). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-django-backend-server/` | Backend and server-side security |
| `stack-django-api-integration/` | API and integration security |
| `stack-django-identity-access/` | Identity, authentication, and access control |
| `stack-django-cryptography/` | Cryptography and key management |
| `stack-django-network-transport/` | Network and transport security |
| `stack-django-secrets-config/` | Secrets and configuration |
| `stack-django-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-django-ai-ml-security/` | AI and ML system security |
| `stack-django-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-django-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-django-payments-fintech/` | Payments and financial flows |
| `stack-django-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-django-server-framework-security/` | Server framework and runtime security |
| `stack-django-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-django-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-django-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

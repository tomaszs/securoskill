# Next.js security (stack domains)

Orchestrator for **Next.js** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-nextjs-frontend-client/` | Frontend and client-side security |
| `stack-nextjs-backend-server/` | Backend and server-side security |
| `stack-nextjs-api-integration/` | API and integration security |
| `stack-nextjs-identity-access/` | Identity, authentication, and access control |
| `stack-nextjs-cryptography/` | Cryptography and key management |
| `stack-nextjs-secrets-config/` | Secrets and configuration |
| `stack-nextjs-ai-ml-security/` | AI and ML system security |
| `stack-nextjs-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-nextjs-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-nextjs-payments-fintech/` | Payments and financial flows |
| `stack-nextjs-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-nextjs-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-nextjs-web-framework-security/` | Web UI framework security |
| `stack-nextjs-server-framework-security/` | Server framework and runtime security |
| `stack-nextjs-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-nextjs-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-nextjs-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

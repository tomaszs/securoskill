# NestJS security (stack domains)

Orchestrator for **NestJS** (Node.js server). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-nestjs-backend-server/` | Backend and server-side security |
| `stack-nestjs-api-integration/` | API and integration security |
| `stack-nestjs-identity-access/` | Identity, authentication, and access control |
| `stack-nestjs-cryptography/` | Cryptography and key management |
| `stack-nestjs-network-transport/` | Network and transport security |
| `stack-nestjs-secrets-config/` | Secrets and configuration |
| `stack-nestjs-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-nestjs-ai-ml-security/` | AI and ML system security |
| `stack-nestjs-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-nestjs-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-nestjs-payments-fintech/` | Payments and financial flows |
| `stack-nestjs-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-nestjs-server-framework-security/` | Server framework and runtime security |
| `stack-nestjs-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-nestjs-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-nestjs-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

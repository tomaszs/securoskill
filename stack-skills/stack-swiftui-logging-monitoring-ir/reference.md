# SwiftUI (iOS): Logging, monitoring, and incident response

Stack-specific implementation for **SwiftUI (iOS)** (Mobile). Normative rules: domain skill `security-logging-monitoring-ir` / `reference.md`.

## Structured logging

**Sub-topics:** Correlation IDs, PII redaction, Threat modeling and trust boundaries (Structured logging), Abuse cases and adversarial testing (Structured logging), Logging, audit, and detection (Structured logging)

### Do (use this in SwiftUI (iOS))

- Store tokens in Keychain with `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`.
- Use ATS (HTTPS).

### Don't

- Do not store secrets in UserDefaults.
- Do not disable ATS globally.

# Hibernate / JPA security (stack domains)

Orchestrator for **Hibernate / JPA** (ORM / data access). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-hibernate-backend-server/` | Backend and server-side security |
| `stack-hibernate-api-integration/` | API and integration security |
| `stack-hibernate-identity-access/` | Identity, authentication, and access control |
| `stack-hibernate-data-databases/` | Data protection and databases |
| `stack-hibernate-cryptography/` | Cryptography and key management |
| `stack-hibernate-ai-ml-security/` | AI and ML system security |
| `stack-hibernate-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-hibernate-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-hibernate-payments-fintech/` | Payments and financial flows |
| `stack-hibernate-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-hibernate-server-framework-security/` | Server framework and runtime security |
| `stack-hibernate-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-hibernate-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-hibernate-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# Spring Boot security (stack domains)

Orchestrator for **Spring Boot** (Java). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-spring-boot-backend-server/` | Backend and server-side security |
| `stack-spring-boot-api-integration/` | API and integration security |
| `stack-spring-boot-identity-access/` | Identity, authentication, and access control |
| `stack-spring-boot-cryptography/` | Cryptography and key management |
| `stack-spring-boot-network-transport/` | Network and transport security |
| `stack-spring-boot-secrets-config/` | Secrets and configuration |
| `stack-spring-boot-logging-monitoring-ir/` | Logging, monitoring, and incident response |
| `stack-spring-boot-ai-ml-security/` | AI and ML system security |
| `stack-spring-boot-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-spring-boot-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-spring-boot-payments-fintech/` | Payments and financial flows |
| `stack-spring-boot-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-spring-boot-server-framework-security/` | Server framework and runtime security |
| `stack-spring-boot-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-spring-boot-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-spring-boot-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

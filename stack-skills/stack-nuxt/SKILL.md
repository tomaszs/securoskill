# Nuxt security (stack domains)

Orchestrator for **Nuxt** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-nuxt-frontend-client/` | Frontend and client-side security |
| `stack-nuxt-backend-server/` | Backend and server-side security |
| `stack-nuxt-api-integration/` | API and integration security |
| `stack-nuxt-identity-access/` | Identity, authentication, and access control |
| `stack-nuxt-cryptography/` | Cryptography and key management |
| `stack-nuxt-secrets-config/` | Secrets and configuration |
| `stack-nuxt-ai-ml-security/` | AI and ML system security |
| `stack-nuxt-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-nuxt-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-nuxt-payments-fintech/` | Payments and financial flows |
| `stack-nuxt-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-nuxt-serverless-edge/` | Serverless, edge, and FaaS security |
| `stack-nuxt-web-framework-security/` | Web UI framework security |
| `stack-nuxt-server-framework-security/` | Server framework and runtime security |
| `stack-nuxt-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-nuxt-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-nuxt-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

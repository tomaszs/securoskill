# Google Cloud security (stack domains)

Orchestrator for **Google Cloud** (Cloud). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-gcp-backend-server/` | Backend and server-side security |
| `stack-gcp-api-integration/` | API and integration security |
| `stack-gcp-identity-access/` | Identity, authentication, and access control |
| `stack-gcp-cryptography/` | Cryptography and key management |
| `stack-gcp-cloud-infrastructure/` | Cloud and infrastructure security |
| `stack-gcp-ai-ml-security/` | AI and ML system security |
| `stack-gcp-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-gcp-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-gcp-payments-fintech/` | Payments and financial flows |
| `stack-gcp-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-gcp-file-object-storage/` | File, blob, and object storage security |
| `stack-gcp-zero-trust-access/` | Zero trust and secure access |
| `stack-gcp-server-framework-security/` | Server framework and runtime security |
| `stack-gcp-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-gcp-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-gcp-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

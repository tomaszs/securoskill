# SQLAlchemy security (stack domains)

Orchestrator for **SQLAlchemy** (ORM / data access). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-sqlalchemy-backend-server/` | Backend and server-side security |
| `stack-sqlalchemy-api-integration/` | API and integration security |
| `stack-sqlalchemy-identity-access/` | Identity, authentication, and access control |
| `stack-sqlalchemy-data-databases/` | Data protection and databases |
| `stack-sqlalchemy-cryptography/` | Cryptography and key management |
| `stack-sqlalchemy-ai-ml-security/` | AI and ML system security |
| `stack-sqlalchemy-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-sqlalchemy-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-sqlalchemy-payments-fintech/` | Payments and financial flows |
| `stack-sqlalchemy-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-sqlalchemy-server-framework-security/` | Server framework and runtime security |
| `stack-sqlalchemy-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-sqlalchemy-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-sqlalchemy-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

# MySQL / MariaDB security (stack domains)

Orchestrator for **MySQL / MariaDB** (Database). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-mysql-backend-server/` | Backend and server-side security |
| `stack-mysql-api-integration/` | API and integration security |
| `stack-mysql-identity-access/` | Identity, authentication, and access control |
| `stack-mysql-data-databases/` | Data protection and databases |
| `stack-mysql-cryptography/` | Cryptography and key management |
| `stack-mysql-ai-ml-security/` | AI and ML system security |
| `stack-mysql-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-mysql-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-mysql-payments-fintech/` | Payments and financial flows |
| `stack-mysql-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-mysql-server-framework-security/` | Server framework and runtime security |
| `stack-mysql-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-mysql-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-mysql-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

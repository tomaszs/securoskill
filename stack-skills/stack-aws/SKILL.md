# Amazon Web Services security (stack domains)

Orchestrator for **Amazon Web Services** (Cloud). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-aws-backend-server/` | Backend and server-side security |
| `stack-aws-api-integration/` | API and integration security |
| `stack-aws-identity-access/` | Identity, authentication, and access control |
| `stack-aws-cryptography/` | Cryptography and key management |
| `stack-aws-cloud-infrastructure/` | Cloud and infrastructure security |
| `stack-aws-ai-ml-security/` | AI and ML system security |
| `stack-aws-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-aws-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-aws-payments-fintech/` | Payments and financial flows |
| `stack-aws-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-aws-file-object-storage/` | File, blob, and object storage security |
| `stack-aws-zero-trust-access/` | Zero trust and secure access |
| `stack-aws-server-framework-security/` | Server framework and runtime security |
| `stack-aws-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-aws-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-aws-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

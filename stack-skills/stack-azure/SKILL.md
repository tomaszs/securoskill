# Microsoft Azure security (stack domains)

Orchestrator for **Microsoft Azure** (Cloud). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-azure-backend-server/` | Backend and server-side security |
| `stack-azure-api-integration/` | API and integration security |
| `stack-azure-identity-access/` | Identity, authentication, and access control |
| `stack-azure-cryptography/` | Cryptography and key management |
| `stack-azure-cloud-infrastructure/` | Cloud and infrastructure security |
| `stack-azure-ai-ml-security/` | AI and ML system security |
| `stack-azure-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-azure-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-azure-payments-fintech/` | Payments and financial flows |
| `stack-azure-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-azure-file-object-storage/` | File, blob, and object storage security |
| `stack-azure-zero-trust-access/` | Zero trust and secure access |
| `stack-azure-server-framework-security/` | Server framework and runtime security |
| `stack-azure-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-azure-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-azure-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

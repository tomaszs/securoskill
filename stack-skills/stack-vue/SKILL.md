# Vue.js security (stack domains)

Orchestrator for **Vue.js** (Web UI). Each row is a domain where this stack has concrete `reference.md` guidance.

| Domain skill folder | Security domain |
|---------------------|-----------------|
| `stack-vue-frontend-client/` | Frontend and client-side security |
| `stack-vue-backend-server/` | Backend and server-side security |
| `stack-vue-api-integration/` | API and integration security |
| `stack-vue-identity-access/` | Identity, authentication, and access control |
| `stack-vue-cryptography/` | Cryptography and key management |
| `stack-vue-ai-ml-security/` | AI and ML system security |
| `stack-vue-business-logic-abuse/` | Business logic and abuse prevention |
| `stack-vue-email-notifications/` | Email and notifications security |
| `stack-vue-realtime-messaging/` | Real-time, WebSocket, and messaging |
| `stack-vue-payments-fintech/` | Payments and financial flows |
| `stack-vue-multi-tenancy-saas/` | Multi-tenancy and SaaS isolation |
| `stack-vue-web-framework-security/` | Web UI framework security |
| `stack-vue-server-framework-security/` | Server framework and runtime security |
| `stack-vue-data-engineering-analytics/` | Data engineering, analytics, and BI security |
| `stack-vue-human-factors-abuse/` | Human factors, social engineering, and support abuse |

## Usage

Load `stack-vue-<domain>` for the domain you are working on, or invoke this orchestrator to pick a folder from the table.

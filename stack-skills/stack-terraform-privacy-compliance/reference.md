# Terraform: Privacy and compliance

Stack-specific implementation for **Terraform** (Infrastructure). Normative rules: domain skill `security-privacy-compliance` / `reference.md`.

## Data subject rights

**Sub-topics:** Erasure, Export, Rectification, Threat modeling and trust boundaries (Data subject rights), Abuse cases and adversarial testing (Data subject rights)

### Do (use this in Terraform)

- Pin module versions; store state in encrypted remote backend.
- Use `terraform plan` in CI with policy checks.

### Don't

- Do not commit `terraform.tfstate` with secrets.
- Do not use `0.0.0.0/0` security groups without review.

### Verify

- tfsec/checkov on every PR.

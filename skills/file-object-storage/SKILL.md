# File, blob, and object storage security

## When to use

Load this skill when work touches **file, blob, and object storage security**: design, implementation, code review, or incident follow-up.

## Workflow

1. Skim sub-areas in [rules.md](rules.md) and pick those that match the change.
2. Apply rules from **policy → design → implementation → verification → operations** for each matching sub-area.
3. For SQL injection, XSS, SSRF, authz, secrets, or other classics, use the dedicated sub-section rather than generic advice.
4. Record gaps as security requirements or tests before merge.

## Sub-areas covered

- **Upload validation**: MIME sniffing, Double extensions, Polyglot files, …
- **Malware scanning**: Async scan, Quarantine buckets, Bypass timing, …
- **Presigned URLs**: TTL, Method restriction, Object key guessing, …
- **Bucket policies and ACLs**: Public read, ListBucket, AuthenticatedUsers, …
- **CDN and origin access**: OAC/OAI, Hotlinking, Cache key abuse, …
- **Image and media processing**: ImageTragick class bugs, SVG uploads, EXIF leaks, …
- **Document preview**: PDF JS, Office macros, HTML conversion, …
- **User-generated content hosting**: Separate domain, CSP on static, COEP/COOP, …
- **Versioning and lifecycle**: Deleted object recovery, Retention locks, Legal hold, …
- **Object encryption**: SSE-KMS, Client-side keys, Bucket keys, …
- **Metadata and headers**: x-amz-meta PII, Directory listings, Error XML, …
- **Archives and backups**: Tar paths, Encrypted backups, Offsite sync, …
